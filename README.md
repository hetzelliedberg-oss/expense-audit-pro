# 💎 ExpenseAudit Pro: ระบบหลังบ้านอัจฉริยะ ตรวจสอบและแยกค่าใช้จ่ายทางการเงิน

ระบบ Web Back-Office สำหรับคัดแยกและตรวจสอบค่าใช้จ่ายจากภาพสลิปโอนเงินธนาคารไทย, บิลบัตรเครดิต, ใบเสร็จรับเงิน (7-Eleven, Makro, Lotus, ปั๊มน้ำมัน) และสเตทเม้นท์ รองรับการ **อัปโหลดภาพแบบไม่อั้น (100–200+ รูปในคลิกเดียว)** พร้อมระบบ **Audit & Recheck ตรวจจับสลิปซ้ำ** และส่งออกรายงานสรุป Excel/CSV แบบมืออาชีพ

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **อัปโหลดภาพแบบไม่อั้น (Batch Drag & Drop)**:
   - ลากและวาง หรือเลือกรูปภาพคราวละ 100–200+ รูปได้ในคลิกเดียว
   - มีระบบ Background Queue Worker ประมวลผลแบบขนาน ไม่ทำให้หน้าเว็บค้าง
   - แถบ Progress Bar แสดงสถานะการสแกนแบบ Real-time (`45 / 150 รูป (30%)`)

2. **AI Multimodal Vision (Google Gemini 2.5 Flash)**:
   - ถอดรหัสสลิปธนาคารไทยทุกแห่ง (กสิกร, ไทยพาณิชย์, กรุงไทย, กรุงเทพ, ทีทีบี, ออมสิน, กรุงศรี, พร้อมเพย์)
   - แปลงปี พ.ศ. เป็น ค.ศ. อัตโนมัติ พร้อมสกัดวันและเวลาอย่างแม่นยำ
   - สกัดยอดเงิน, ค่าธรรมเนียม, ภาษี VAT, ชื่อผู้รับ/ร้านค้า, ผู้โอน, และรหัสอ้างอิงธุรกรรม
   - จัดหมวดหมู่ค่าใช้จ่ายหลักและย่อยอัตโนมัติ (อาหาร, เดินทาง, ค่าน้ำมัน, บิล, ค่าเช่า, ธุรกิจ ฯลฯ)

3. **Audit & Recheck Engine (ระบบตรวจสอบและตรวจจับสลิปซ้ำ)**:
   - **Exact Duplicate Detection**: ตรวจจับรูปซ้ำ 100% (SHA-256) หรือรหัสอ้างอิงสลิป (Reference ID) ที่ตรงกัน
   - **Fuzzy Duplicate Detection**: แจ้งเตือนเมื่อพบยอดเงินตรงกันในวันเดียวกันกับร้านค้าเดียวกัน (ป้องกันการนับยอดซ้ำกรณีมีทั้งสลิปและสเตทเม้นท์)
   - **Math Audit**: ตรวจสอบผลรวม ยอดเงิน + ค่าธรรมเนียม ให้สัมพันธ์กับยอดรวมสุทธิ

4. **มุมมองสรุปรายวันและรายเดือน (Daily & Monthly Breakdown)**:
   - **ตารางสรุปรายวัน (Daily)**: รวมยอดรายจ่าย-รายรับแยกแต่ละวัน พร้อมคลิกเข้าไปดูรายการย่อย
   - **กราฟสรุปรายเดือน (Monthly)**: กราฟแท่งเปรียบเทียบแนวโน้มรายรับ-รายจ่ายแต่ละเดือน และกราฟโดนัทสัดส่วนหมวดหมู่
   - **Smart Filters**: ค้นหาร้านค้า, กรองหมวดหมู่, กรองเฉพาะรายการที่พบข้อสังเกต (Audit Warning), เลือกช่วงวันที่

5. **Side-by-Side Slip Inspector**:
   - คลิกที่แถวรายการเพื่อเปิดดูรูปสลิปต้นฉบับทางด้านซ้าย เทียบกับข้อมูลที่สกัดได้ทางด้านขวา
   - สามารถแก้ไขข้อมูลหรือกดยืนยัน (Verify) ได้ทันที

6. **ระบบส่งออกรายงาน (Professional Excel & CSV Export)**:
   - **Excel (.xlsx)**: สร้างรายงาน 3 ชีตอัตโนมัติ
     - *Sheet 1 (Summary)*: สรุปภาพรวมและสัดส่วนเปอร์เซ็นต์หมวดหมู่
     - *Sheet 2 (Daily)*: สรุปยอดรวมแยกแต่ละวัน
     - *Sheet 3 (Transactions)*: ตารางรายการทั้งหมดพร้อมตัวเลขจัดรูปแบบและสีเตือนสลิปซ้ำ
   - **CSV (UTF-8 with BOM)**: รองรับภาษาไทย 100% เปิดใน Excel ได้ไม่เพี้ยน

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. วิธีคลิกเดียว (Windows)
ดับเบิลคลิกที่ไฟล์:
```
run.bat
```
ระบบจะเปิดเบราว์เซอร์และเข้าไปที่ `http://127.0.0.1:5000` ให้อัตโนมัติ

### 2. วิธีรันผ่าน Terminal
```bash
# ติดตั้งแพ็กเกจ (ทำเพียงครั้งแรก)
pip install -r requirements.txt

# สตาร์ทเซิร์ฟเวอร์
python app.py
```
เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:5000`

## 🔑 การตั้งค่า Google Gemini API Key
1. กดที่ไอคอนรูป **ฟันเฟือง (Settings)** ที่มุมขวาบนของหน้าเว็บ
2. วาง Gemini API Key ของคุณ แล้วกด **บันทึก Key**
*(หากยังไม่มี Key ระบบจะใช้ Mock Engine จำลองข้อมูลให้สามารถทดลองใช้งานและทดสอบระบบ Audit ได้ทันที)*
